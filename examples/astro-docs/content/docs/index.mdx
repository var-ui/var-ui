# Documentation

This example app dogfoods `@var-ui/docs` as a general technical docs site — chrome, routing,
and theming without design-system catalog plugins.

## What you'll find here

- **Getting started** — run the example and explore the shell
- **Installation** — packages this site depends on

Use the header **color mode** control (light / dark / system) to verify token-driven theming.
