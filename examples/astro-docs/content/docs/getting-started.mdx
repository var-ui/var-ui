# Getting started

## Run the example

From the monorepo root:

```bash
pnpm astro-docs:dev
```

Or:

```bash
vp run @var-ui/example-astro-docs#dev
```

Open the URL Astro prints (usually `http://localhost:4321`), then visit `/docs`.

## What the shell includes

- Top nav + sidebar from the site layout
- Auto TOC on guide pages
- Client search over the seeded index
- `ColorModeToggle` with system preference (kit default)
