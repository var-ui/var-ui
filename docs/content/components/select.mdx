# Select

Dropdown single-select. `Select` with `options` is the assembled preset (`label`, `description`, `errorMessage`, `placeholder`). Compose `Select.Root`, `Select.Trigger`, `Select.Popover`, `Select.ListBox`, and `Select.Item` when a row needs more than a label.

Custom item rows are React-only. Astro and HTML previews keep using a native `<select>` with the core recipe classes.
