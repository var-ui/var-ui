# DropdownMenu

Action menu opened from a trigger button. Pass `sections` of items (optional section labels, shortcuts, `danger`, `disabled`). The same `MenuContent` primitive powers `ContextMenu` and `MoreMenu`.

## Examples

### Default

Provide a `trigger` element (usually a `Button`) and a flat list of items in one section.

## Accessibility

Built on React Aria `MenuTrigger` / `Menu`. The trigger receives focus; arrow keys move between items, Enter/Space activates, Escape closes. Give destructive items clear labels (“Delete…”) — `danger` is visual only. Disabled items stay in the list but are not activatable.
