# Outline

In-page outline navigation. Pass a flat `items` array (or `Outline.Item` children) and highlight via controlled `activeId` or automatic scroll-spy.

## Accessibility

The root is a `nav` landmark named by `title` (default “On this page”). Links target `#id` — keep matching heading `id`s in the page. When scroll-spy is on, the active link updates from an `IntersectionObserver`; pass `activeId` to control highlighting yourself.
