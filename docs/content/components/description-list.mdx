# DescriptionList

Semantic key/value display using `<dl>` / `<dt>` / `<dd>`. Compose with `DescriptionList.Item` or an `items` array; optionally collapse with `maxItems`.

A titled single-column metadata block.

## Accessibility

Uses native description-list semantics (`dl`/`dt`/`dd`). Keep labels short and unique within the list. When `maxItems` enables “Show more”, the toggle is a real button for keyboard users.
