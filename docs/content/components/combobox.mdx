# Combobox

Headless combobox built on React Aria `ComboBox`. Compose `Root`, `Label`, `Input`,
`Description`, `Error`, `Popover`, `ListBox`, and `Item` for autocompletes, searchable
selects, and other filterable pickers.

For the common single-select search field, use [`Typeahead`](/components/typeahead) instead.

## Accessibility

Built on React Aria Components. The input exposes `role="combobox"`; the listbox opens
on focus or typing and supports keyboard navigation.
