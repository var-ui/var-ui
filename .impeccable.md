## Design Context

### Users

Frontend developers and design engineers with a strong eye for visual quality. They use Var UI to evaluate, adopt, theme, and extend an accessible design system across React, Astro, and HTML projects.

### Brand Personality

Expressive, inventive, human.

### Aesthetic Direction

A design-system identity grounded in code without feeling sterile or generic. The homepage wordmark should read as a large, intentional CSS expression: `var(--ui)` in a monospace face, with syntax highlighting that derives from Var UI design tokens and follows the active color mode. The visual language should feel authored and playful enough to be memorable while remaining precise and credible to technical users.

### Design Principles

- Make the system’s CSS-native point of view visible in the brand itself.
- Use expressive syntax color as a meaningful visual hierarchy, never as decoration detached from the product.
- Let the active design theme and light/dark mode own the palette.
- Keep technical details human-readable, semantic, and accessible.
- Prefer a distinctive, focused gesture over generic visual effects.
